轻量、主题无关的电子商城系统，兼容 Astra 主题与 Elementor，账户中心一体化：实物 / 虚拟下载 / 卡密商品、购物车、订单、会员等级、积分与签到。

== Description ==

月光商城是一个轻量、主题无关的电子商城系统：不依赖 WooCommerce，激活即建页面，短代码 + Elementor 组件均可用。

**商品与订单**

* 商品自定义文章类型：实物 / 虚拟下载 / 卡密 三种类型
* 会话购物车（游客可用，Cookie 存储），游客凭邮箱下单、凭 48 位访问令牌取货
* 卡密商品：AES-256-CBC 加密批次库存池，明文不落库，售出自动分配，库存自动邮件预警
* 虚拟商品：支付后自动生成限时安全下载链接

**支付**

* 内置网关：支付宝（电脑网站支付，RSA2 自实现）、微信支付 v3（Native 扫码 / H5）、PayPal、Stripe、余额支付、积分支付、货到付款、扫码 / 线下转账
* 支付回调验签 + 金额比对 + 幂等三重保障；服务端取价，前端零金额字段
* 统一退款：售后申请 → 规则闸校验 → 全额 / 部分退款 → 库存回滚、钱包 / 积分原路回补

**积分体系**

* 全局兑换比例后台可配，同时作用于充值、订单积分支付、商品积分价自动换算三处
* 每日签到送积分（基础奖励 + 连续加成，后台可配），入账与商城积分同一账本
* 积分流水利账本级并发安全（SQL 条件更新 + 命名锁）

**会员与账户**

* 会员等级后台自定义（名称 / 价格 / 有效期 / 会员价），到期自动降级
* 账户中心：概览、资料、会员等级、已购内容、积分余额与签到、订单、收货地址、我的下载、优惠券
* 前端登录 / 注册 / 找回密码页面自动创建，支持第三方登录（OAuth）与头像库

**物流**

* 运费模板（固定 / 按件计费、满额包邮）、到店自提、收货地址簿
* 发货单管理、快递100 聚合轨迹查询（15 分钟自动同步）、签收自动完成

**数据说明（第三方服务）**

本插件默认不向作者服务器发送任何数据。仅在以下情形产生对外传输：

* 支付网关：支付宝 / 微信 / PayPal / Stripe 按各支付服务商要求，将订单号、金额、商品标题等传至相应服务商以完成支付（需管理员自行配置密钥）；
* 快递100 轨迹查询（可选）：配置 Key 后，将运单号发送至快递100 查询物流轨迹；
* 授权中心（可选，仅销售 Pro 授权的站点需要）：配置后，购买映射商品的订单会将订单号、买家邮箱、商品 / 套餐代码发送到你指定的授权服务器用于自动签发授权码。

插件不会收集或上传任何其它数据。

== Installation ==

1. 在 WordPress 后台「插件 → 安装插件」搜索「漫步白月光电子商城」安装并启用；
2. 激活后自动创建商品 / 购物车 / 结算 / 登录 / 注册 / 账户中心等页面；
3. 进入「商品 → 商城設置」配置货币、支付网关、运费与积分；
4. 在「商品 → 添加商品」创建第一批商品，即可开始售卖。

== Frequently Asked Questions ==

= 需要安装 WooCommerce 吗？ =

不需要。月光商城是独立的商城系统，自带商品、订单、购物车与支付，不依赖 WooCommerce；同时提供从 WooCommerce 一键迁入商品的工具。

= 游客可以下单吗？ =

可以。默认开启「允許訪客購買」，访客填写邮箱即可下单；付款后订单页与邮件会推荐其注册。可在设置中关闭。

= 积分怎么获得、怎么使用？ =

用户在账户中心「积分余额」充值（后台可配套餐与比例），也可每日签到获取；结算页选择「积分支付」按比例全额扣分，退款自动回补。

= 支持哪些支付方式？ =

支付宝（仅 CNY）、微信支付 v3（仅 CNY）、PayPal、Stripe、余额、积分、货到付款、线下转账。所有网关均可通过 `mlshop_payment_gateways` 过滤器扩展。

= 我的服务器需要什么环境？ =

WordPress 5.8+，PHP 7.4+。支付宝 / 微信支付需要服务器启用 OpenSSL 扩展。
